Cozy Quotes is an iOS-first quote collector built with Expo and React Native. Save passages
from books, articles or conversations, tag them, search them later — and let a home screen
widget quietly bring one of them back.

Everything lives on the device. No account, no backend, no analytics, no network calls.

## Why

Most quote apps ask you to open them. Cozy Quotes does the opposite: the widget puts a saved
line on your home screen, so the collection stays part of the day instead of becoming another
forgotten list. The interface follows the same idea — serif type, paper palette, soft motion,
nothing shouting for attention.

## Features

- **Save passages** — quote text, author, source and comma-separated tags; paste straight from the clipboard.
- **Home feed** — a featured quote with `Another` for a random pick and a one-tap favorite.
- **Library** — full-text search across quote, author and source; filter by favorites and by tag.
- **Editing** — update or delete any saved quote from its detail screen.
- **Widget** — small and medium WidgetKit widgets showing either a random quote or a favorite.
- **Local-first storage** — SQLite on device, settings in MMKV, no cloud dependency.
- **Light & dark themes** — follows the system appearance.
- **Haptics** — selections and confirmations where they matter.

## Tech stack

| Layer | Choice |
| --- | --- |
| Runtime | Expo SDK 54, React Native 0.81, React 19.1 |
| Navigation | expo-router 6 (file-based routes) |
| Language | TypeScript, `strict` mode |
| Storage | expo-sqlite (WAL) for quotes, react-native-mmkv for settings |
| UI | react-native-reanimated 4, expo-haptics, custom theme |
| Widget | SwiftUI + WidgetKit, generated by a local Expo config plugin |
| Native bridge | `RCT_EXTERN_MODULE` module writing to an App Group's `UserDefaults` |

The New Architecture is enabled (`newArchEnabled: true`), which is required by react-native-mmkv v4.

## Requirements

- macOS with Xcode 16.1+ and an iOS Simulator
- Node.js **20.19+** (22 LTS recommended)
- CocoaPods (`brew install cocoapods` if missing)
- iOS 17+ (the widget target's deployment target)
- Apple Developer account — only for running on a physical device / shipping the widget

## Getting started

The app uses native modules and a custom widget extension, so **Expo Go will not work**.
A development build is required.

```bash
git clone git@github.com:nickkupriyanov/margin.git
cd margin
npm install
npm run prebuild     # generates ios/ via Expo CNG (the config plugin adds the widget target)
npm run ios          # builds and launches on the iOS Simulator
```

After the first native build, start Metro for JS-only changes:

```bash
npm start
```

The first `npm run ios` takes a while: it runs `pod install` and compiles React Native from
source. Subsequent builds are incremental.

### Running on a physical device

```bash
npx expo run:ios --device
```

Before that, open `ios/CozyQuotes.xcworkspace` and:

1. Select your team under **Signing & Capabilities** for both the `CozyQuotes` and
   `CozyQuotesWidget` targets.
2. Make sure the **App Groups** capability is enabled with
   `group.com.nickkupriyanov.cozyquotes` on both targets.
3. Use your own bundle identifiers in `app.json` and `plugins/withCozyQuotesIos.js` props
   so they match the identifiers registered in the Apple Developer portal.

Without a matching App Group the app still runs, but the widget cannot read quote data.

### Adding the widget

1. Build and open the app at least once.
2. Long-press the home screen → **+** → search for **Cozy Quotes**.
3. Pick the small or medium size.
4. Add a couple of quotes in the app; the widget reloads its timeline on every change.

## Project structure

```text
app/                       # expo-router screens
  _layout.tsx              # stack + QuotesProvider
  index.tsx                # home / featured quote
  add.tsx                  # create a quote
  library.tsx              # list, search, favorites, tags
  settings.tsx             # widget preference
  quote/[id].tsx           # quote detail, edit, delete
src/
  components/              # QuoteCard, QuietButton, AmbientGrain
  data/fallbackQuote.ts    # shown when the library is empty
  hooks/useQuotes.tsx      # single source of truth, SQLite + widget sync
  storage/database.ts      # SQLite schema and queries
  storage/settings.ts      # MMKV-backed widget preference
  theme/                   # palette and typography
  types/quote.ts           # Quote, QuoteDraft, WidgetSnapshot
  widgets/widgetSnapshot.ts# builds the payload and calls the native bridge
plugins/
  withCozyQuotesIos.js     # generates the widget extension, bridge and entitlements
assets/                    # icon, splash, adaptive icon
ios/                       # generated by `expo prebuild` — not committed
```

`ios/` and `android/` are intentionally gitignored: they are produced by Expo's
[Continuous Native Generation](https://docs.expo.dev/workflow/continuous-native-generation/).
Edit `app.json` and the config plugin instead of files inside `ios/`, or your changes will be
lost on the next prebuild.

## How it works

1. `QuotesProvider` opens `cozy-quotes.db`, creates the `quotes` table if needed and loads all rows.
2. Every mutation (add, update, delete, favorite) refreshes state and rebuilds a small
   `WidgetSnapshot` JSON.
3. On iOS, `publishWidgetSnapshot` calls the native `CozyWidgetBridge.writeSnapshot`, which
   stores the JSON in `UserDefaults(suiteName: "group.com.nickkupriyanov.cozyquotes")` under
   `widgetPayload` and calls `WidgetCenter.shared.reloadAllTimelines()`.
4. The SwiftUI provider decodes that payload, falls back to bundled text when nothing is saved,
   and asks WidgetKit for a refresh every six hours.

The widget preference (`random` / `favorites`) is stored in MMKV and applied when the next
snapshot is built.

## Troubleshooting

**"Cannot find native module" in Expo Go**
Use a development build (`npm run ios`); Expo Go does not include MMKV, SQLite binaries
or the widget bridge.

**The widget is empty or stuck on the fallback quote**
Check that the App Group identifier is identical in three places: `app.json`, the props in
`plugins/withCozyQuotesIos.js`, and the entitlements of both targets. Then rebuild, open the
app once and add a quote. On a device, confirm the App Group capability is enabled in the
Apple Developer portal.

**Native changes are not picked up**
Regenerate the project and reinstall pods:

```bash
npx expo prebuild --clean --platform ios
cd ios && pod install && cd ..
npm run ios
```

**The widget does not update immediately**
WidgetKit throttles reloads. The app requests a reload on every data change, but the system
may coalesce them; the timeline also refreshes every six hours.

**Stale SQLite data while developing**
Delete the app from the simulator (or run `npx expo run:ios --device` after uninstalling) to
start with an empty database.

## Limitations & roadmap

- iOS only; the Android build has no widget equivalent.
- No import/export, backup or iCloud sync yet — local data is lost if the app is uninstalled.
- No share extension, so saving a highlight still means copying and pasting.
- No tests or CI; `npm run typecheck` is the current safety net.

Planned directions:

- [ ] Share Extension for saving highlights from other apps
- [ ] JSON/Markdown export and iCloud backup
- [ ] Import highlights from Apple Books
- [ ] OCR a page photo and prefill the quote
- [ ] Shareable quote cards
- [ ] Android widget
- [ ] Unit tests for the storage layer and widget snapshot

## Privacy

Cozy Quotes makes no network requests. Quotes and settings never leave the device; the widget
reads them through a shared App Group container.
